# 页间 PDF 1.1.0 · 完整介绍

> 我做页间 PDF，就是为了让自己拥有纯粹、安静、专注的阅读体验。

页间把设计重点放在“打开文档之后，能不能舒服地读下去”。它提供 Windows x64 与 macOS Universal 两种安装包，让使用不同系统的人都能拥有这套简约安静的阅读方式。

## 1. 为内容留下空间

文档居中呈现，常用操作集中在顶部和底部。背景、纸墨和阅读控制各有自己的位置，外观设置以侧边面板展开。需要更大的阅读空间时，可以切换全屏。

这类设计的价值在于降低界面对注意力的争夺，让阅读成为主要活动。这里的“纯粹”首先是一种创作初衷和设计取向。

## 2. 背景与纸墨分别调整

“背景”是 PDF 页面外的阅读环境；“纸墨”改变 PDF 页面的显示配色。两者可以独立选择。例如，喜欢宣纸背景的人，也可以给 PDF 选择夜间纸墨。

24 种背景 × 15 种预设纸墨，提供 **360 种预设搭配**；此外还可以自定义。这里的 360 指组合数量，不代表 360 个不同的内置主题。

### 全部 24 种阅读背景

| 分类 | 背景 |
| --- | --- |
| 素色 | 宣纸、雪白、青雾、米沙、墨夜、松烟 |
| 渐变 | 晨曦、暮云、远山、海盐、夜航、极光 |
| 纹理 | 亚麻、纸纹、大理石、木桌、水磨石、炭黑 |
| 氛围 | 星空、烛光、雨窗、苔原、落日、留白 |

浅色背景适合明亮、开阔的视觉偏好；深色背景适合较低亮度的阅读环境；纹理与氛围背景则更强调空间感。哪一种更舒服，取决于屏幕、环境和个人偏好。

### 全部 15 种页面纸墨

| 纸墨 | 显示特点 |
| --- | --- |
| 原色 | 使用 PDF 原本的页面颜色，是核对图表颜色时的优先选择 |
| 夜间 | 深色纸面搭配浅色文字 |
| 纯黑 | 黑色纸面搭配白色文字 |
| 墨灰 | 深灰纸面搭配柔和浅色文字 |
| 夜间彩色 | 通过显示滤镜形成带色彩的夜间效果；颜色可能变化 |
| 护眼 | 暖米色纸面与深色文字；“护眼”是预设名称 |
| 羊皮纸 | 复古的暖色纸张风格 |
| 灰阶 | 简洁的浅灰与深色搭配 |
| 森林 | 深绿纸面与浅绿文字 |
| 海夜 | 深蓝纸面与浅蓝文字 |
| 玫瑰 | 深玫瑰色纸面与浅色文字 |
| 黑金 | 深色纸面与暖金色文字 |
| 青瓷 | 清淡的青绿色纸面 |
| 琥珀 | 温暖的浅黄纸面 |
| 夜紫 | 深紫纸面与浅紫文字 |

除原色和夜间彩色外，上述预设按整页明暗映射到纸色与墨色，图片也会一起着色。它们改变的是阅读显示效果，不是编辑并导出 PDF 文件。需要查看原始图像颜色时，请切回“原色”。

## 3. 把阅读环境调成自己的样子

- **本地图片背景**：选择自己的图片作为背景，支持常见 JPG、PNG 等图片。图片转换后存入本机存储，不需要上传至服务器。
- **背景暗度**：可在 0%–60% 间调整。
- **背景虚化**：可在 0–16 像素间调整，让背景更柔和。
- **界面文字颜色**：自动判断背景明暗，或手动指定深色、浅色文字。
- **自定义纸墨**：单独选择纸张和文字的颜色，并预览、应用。
- **恢复默认**：可以恢复默认背景或原色纸墨，方便重新搭配。

自定义背景受本机存储容量限制；图片过大、无法持久保存时，软件会提示仅在本次会话内有效。

## 4. PDF 在本机打开

页间把 PDF.js 阅读引擎、字符映射和常用字体资源随桌面应用提供。选择文件后，软件在设备本地读取和解析；核心阅读过程不依赖云端转换，也不要求登录账户。

桌面程序的网络连接策略限制到自身资源、本地数据和临时对象，应用内未发现 PDF 上传流程。这里说明的是当前版本的实现与工作方式，不把它扩展成独立安全审计或对所有运行环境的绝对保证。

密码保护的 PDF 会显示密码输入框，提供密码后继续打开；这不是移除保护或绕过密码的功能。

## 5. 阅读过程顺手连贯

| 功能 | 用法与价值 |
| --- | --- |
| 连续滚动 | 文档按页面连续排列，向下滚动即可接着读 |
| 上下页切换 | 点击底部按钮，或使用左右方向键 |
| 页码跳转 | 在底部页码框输入页数并确认，快速到达目标页 |
| 页面缩略图 | 按 T 打开“页面目录”，查看逐页缩略图并点击定位 |
| 阅读进度 | 当前页、总页数和顶部进度线帮助判断阅读位置 |
| 缩放 | 50%–250%，按钮或加减键每次调整 10 个百分点 |
| 滚轮缩放 | 按住 Ctrl（Windows）或 ⌘（Mac）滚动滚轮，连续调整大小 |
| 适应宽度 | 点击适应宽度按钮或按 0，回到基准适宽布局 |
| 横向查看 | 放大到超出窗口宽度后，可按住页面画布左右拖动；双击可恢复基准缩放 |
| 全屏 | 按 F 进入或退出；Esc 可退出全屏或关闭已打开的面板 |

“页面目录”是逐页缩略图导航，不等同于读取 PDF 中的章节书签。

## 6. 下次回来，接着读

软件在本机保存阅读页码、页内的相对位置和外观、缩放偏好。重新选择同一份文档时，可恢复之前保存的位置；窗口大小和位置也有本地记忆。

当前版本按文件名与文件大小识别阅读记录。文件改名、大小变化、清理本机应用数据，都可能影响恢复；同名且同大小的不同文档可能共用记录。这个功能不包含云同步，也不承诺关闭后自动重新打开文档。

## 7. 对长文档的处理方式

页面和缩略图按可见区域附近排队渲染；远离当前阅读位置的页面画布会释放，再次靠近时重新绘制。这样可以减少始终保留全部页面画布的需求。

这是实现方式上的优势，不是速度或内存基准测试结论。实际表现会受文档页数、图片复杂度和设备性能影响。

## 8. 两个版本怎么选

| 项目 | Windows x64 | macOS Universal |
| --- | --- | --- |
| 文件 | Yejian-PDF-1.1.0-win-x64.exe | Yejian-PDF-1.1.0-mac-universal.dmg |
| 版本 | 1.1.0 | 1.1.0（按提供文件标识） |
| 适用对象 | 64 位 Intel / AMD Windows 电脑 | Mac；Universal 为提供安装包的标识 |
| 平台处理 | 隐藏式标题栏，标题栏颜色跟随明暗外观 | 程序包含 Mac 菜单、交通灯窗口按钮布局和全屏状态处理 |
| 本次核对 | 本机已安装 1.1.0 的实机界面与应用代码 | 安装包与校验值、作者提供的两张 Mac 实机截图；未在本机进行 Mac 安装测试 |

Universal 通常用于同时分发 Intel 和 Apple 芯片版本；本次未解包核实二者架构或在 Mac 上运行，因此不宣称完成兼容性测试。两个文件的体积不能用来比较运行速度、内存占用或阅读质量。最低系统要求、Mac 签名和公证状态有待后续版本说明明确。

## 9. 快捷键速查

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + O / ⌘ + O | 选择并打开 PDF |
| B | 打开或关闭外观面板 |
| T | 打开或关闭页面缩略图目录 |
| F | 切换全屏 |
| ← / → | 上一页 / 下一页 |
| + / - | 放大 / 缩小 |
| 0 | 恢复适应宽度 |
| Ctrl / ⌘ + 滚轮 | 连续缩放 |
| Esc | 关闭当前弹层、面板，或退出全屏 |

输入框正在编辑或面板打开时，部分阅读快捷键会暂停，避免误操作。

## 10. 当前版本的定位

页间适合阅读论文、教材、讲义、报告和电子文档，尤其适合希望自己调节阅读配色、重视本地使用的人。

本次核对未发现 OCR、全文搜索、文字选择高亮、批注编辑、PDF 合并或转换、云同步等功能，因此这些不作为 1.1.0 的宣传卖点。软件没有本次发布可供复现构建的完整源码；本仓库分发产品和介绍资料。

本说明依据本机 Windows 1.1.0 的实际界面、随应用提供的实现和作者提供的 Mac 实机截图整理，版本以本次发布附件为准。视频中的 Windows 截图使用软件内置阅读示例，Mac 截图使用作者指定的两张画面。
