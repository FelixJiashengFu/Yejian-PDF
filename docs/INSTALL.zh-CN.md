# 下载与安装

从 [v1.1.0 Releases](https://github.com/FelixJiashengFu/Yejian-PDF/releases/tag/v1.1.0) 下载。安装包以 Releases 附件分发，仓库文件列表主要放产品说明和截图。

## Windows x64

下载 `Yejian-PDF-1.1.0-win-x64.exe`，在 64 位 Intel / AMD Windows 电脑上按安装向导完成安装。启动“页间 PDF”，点击“打开 PDF”或把 PDF 拖入窗口。

本次发布的 EXE 未包含可验证的 Authenticode 数字签名。请核对下载来源和 SHA-256；如系统阻止安装，遵循系统及设备管理员的信任判断。本说明不要求关闭安全防护。

## macOS

下载 `Yejian-PDF-1.1.0-mac-universal.dmg`，打开磁盘映像，将应用拖到 Applications（应用程序）目录后启动；若映像内的布局不同，以映像内实际安装提示为准。

Universal 是提供文件的命名标识。本次未在 Mac 实机测试，也未核实架构、签名、公证或最低系统版本；如系统显示阻止或不兼容提示，请保留完整提示并反馈，勿将未核实的兼容性当作保证。

## 第一次阅读

1. 打开 PDF，或选择内置“阅读示例”。
2. 按 B 进入外观设置；背景和纸墨分别选择。
3. 按 T 使用逐页缩略图，按 F 切换全屏。
4. 再次打开同一份未改名、大小未变的文件时，软件会尝试恢复本机保存的阅读位置。

遇到问题时，可在本仓库 Issues 说明系统、版本、操作步骤和错误提示。请优先使用可公开的示例文档复现。
